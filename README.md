# Arup Acoustics Floor Vibration Test Analyser

Upload up to five WAV files in one analysis set:

- Background
- Heel Drop
- Walking
- Running
- Jumping

Any file may be omitted. Click **Start analysis** to run all available tests together.

Outputs include a unified summary, time histories, peak amplitude spectra, heel-drop natural-frequency candidates, activity dominant response frequencies, peak acceleration, Excel report with charts, and portrait A4 PDF report.

Deploy with `app.py` as the Streamlit entry point. Python 3.12 is recommended.
