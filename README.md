# Arup Acoustics Floor Vibration Test Analyser v6 Stable

Stability-focused architecture:
- Start Analysis performs numerical analysis only.
- One failed test does not discard successful test results.
- Results are separated into Summary / Heel Drop / Walking / Running / Jumping / Reports tabs.
- Long plots are decimated for browser display only; numerical calculations remain full resolution.
- Heel-drop free-decay curves remain available in expanders.
- Excel and portrait A4 PDF reports are generated only when requested.
- Report-generation errors do not remove analysis results.
